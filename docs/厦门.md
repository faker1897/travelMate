# 厦门旅游攻略

## 城市定位
厦门适合喜欢海边、轻松散步、文艺街区、咖啡馆和短假期疗愈感的人。
它更像一座适合放慢节奏的小型海滨城市。

## 适合人群
- 情侣：鼓浪屿、海边日落和 citywalk 氛围很好
- 朋友和独自旅行：节奏轻松，适合周末度假
- 家庭：海边和亲子玩法都比较友好

## 推荐游玩天数
- 2 天：鼓浪屿 + 环岛路
- 3 天：加上植物园 / 沙坡尾
- 4 天：更适合慢玩和拍照

## 最佳旅游时间
- 春秋更舒适
- 夏季海边体验强，但天气更热
- 台风季出行前要留意天气变化

## 核心景点与玩法
### 鼓浪屿
- 更适合安排半天到一天
- 适合慢走、看建筑和拍照
- 热门时段游客较多

### 环岛路
- 适合骑行、散步和看海
- 傍晚体验更好

### 沙坡尾
- 适合文艺街区、拍照和小店闲逛

### 厦门大学周边 / 南普陀
- 更适合轻松走走和看城市气质

## 住宿区域建议
### 中山路附近
- 吃饭和交通比较方便
- 适合第一次来厦门

### 曾厝垵 / 环岛路附近
- 更适合海边度假和放松
- 热门时段游客也多

## 美食与觅食区域
- 沙茶面、海蛎煎、土笋冻、花生汤是常见代表
- 中山路和八市一带更适合边走边吃

## 交通建议
- 市区不大，打车和公交都能配合
- 重点景点适合分“鼓浪屿线”和“海边线”两天来排

## 常见行程组合
### 3 天轻松版
- Day 1：中山路 + 沙坡尾
- Day 2：鼓浪屿
- Day 3：环岛路 + 海边日落

## 避坑提醒
- 鼓浪屿更适合慢逛，不建议压缩成非常赶的打卡线
- 海边天气影响较大，遇到极端天气要灵活调整
- 如果只玩 2 天，不要把点位排太碎
