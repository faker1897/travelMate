# 杭州旅游攻略

## 城市定位
杭州适合第一次来江南、想兼顾风景、美食、轻松散步和拍照出片的人群。
典型关键词：西湖、寺庙祈福、茶园、湿地、宋韵、citywalk。

## 适合人群
- 情侣：西湖、龙井村、湘湖夜景都很适合慢节奏约会
- 家庭亲子：西溪湿地、宋城、杭州动物园更轻松
- 独自旅行：西湖环线和老城区 citywalk 体验友好
- 朋友出游：可以做西湖 + 灵隐寺 + 茶园 + 夜生活的组合

## 推荐游玩天数
- 1 天：只玩西湖核心区 + 河坊街
- 2 天：西湖核心区 + 灵隐寺 / 龙井村
- 3 天：西湖 + 灵隐寺 + 西溪湿地 / 湘湖

## 最佳旅游时间
- 3 到 5 月：春景最好，适合赏花和环湖散步
- 9 到 11 月：天气稳定，适合长时间步行
- 盛夏：白天偏热，建议把重点放在早晚和夜游
- 冬季：游客相对少，适合偏安静的玩法

## 核心景点与玩法
### 西湖核心区
- 适合首次到杭州的游客
- 推荐动线：断桥 -> 白堤 -> 平湖秋月 -> 曲院风荷 -> 苏堤 -> 雷峰塔
- 想轻松一点可以只选北山街、断桥、湖滨一线
- 看日落可以优先考虑雷峰塔或长桥公园附近

### 灵隐寺和飞来峰
- 适合想看寺庙文化、石刻和山间环境的人
- 建议上午早点去，越晚越拥挤
- 可以与法喜寺、龙井村做一日串联

### 龙井村和九溪
- 适合拍照、喝茶、轻徒步
- 春秋体验最好
- 如果想要更松弛，可以只安排龙井村喝茶 + 九溪轻步行

### 西溪湿地
- 适合家庭、慢游和不想太赶的行程
- 与西湖相比更偏生态休闲
- 建议预留半天到一天

### 河坊街和南宋御街
- 更适合吃小吃、感受游客氛围
- 商业化明显，但第一次来可以短暂停留

## 住宿区域建议
### 西湖东侧 / 湖滨商圈
- 优点：离西湖近，吃饭和交通方便，适合第一次来杭州
- 缺点：热门时段房价偏高

### 凤起路 / 武林广场
- 优点：地铁换乘方便，去西湖和东站都比较顺
- 适合想兼顾通勤效率和住宿性价比的人

### 龙翔桥 / 延安路一带
- 适合想晚上继续逛街、吃饭、看西湖夜景的人
- 节假日人流密集

## 美食与觅食区域
- 杭帮菜代表：东坡肉、龙井虾仁、叫花鸡、片儿川
- 本地小吃：葱包烩、定胜糕、猫耳朵
- 觅食区域：湖滨银泰、武林路、河坊街、黄龙一带
- 想吃得更稳，优先去本地口碑餐馆，不建议在景区正门口随意进店

## 交通建议
- 杭州东站到市区效率高，地铁优先
- 西湖核心区更适合步行、骑行或短途打车
- 节假日西湖周边容易堵车，不建议全程依赖网约车
- 一天内跨很多点时，优先按片区安排，不要来回穿城

## 常见行程组合
### 2 天经典版
- Day 1：西湖核心区 + 雷峰塔 + 湖滨夜景
- Day 2：灵隐寺 + 飞来峰 + 龙井村

### 3 天轻松版
- Day 1：西湖环线慢游
- Day 2：灵隐寺 + 法喜寺 + 龙井村
- Day 3：西溪湿地或湘湖 + 夜间返程

## 避坑提醒
- 节假日西湖边和灵隐寺排队明显，热门时段尽量早出门
- 河坊街适合逛，不一定适合做正餐主场
- 西湖看起来不大，真正步行一圈会很耗体力
- 如果只有 2 天，不建议再硬塞乌镇 / 西塘，容易把节奏拉得很碎
