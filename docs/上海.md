# 上海旅游攻略

## 城市定位
上海适合喜欢城市天际线、博物馆、近代建筑、购物、美食和都市节奏的人。
比较适合 2 到 4 天的城市观光与休闲结合玩法。

## 适合人群
- 第一次到华东大城市的游客
- 情侣和朋友：夜景、商圈、咖啡馆和 citywalk 丰富
- 家庭游客：迪士尼、科技馆等亲子资源多

## 推荐游玩天数
- 2 天：外滩 + 陆家嘴 + 武康路等经典区
- 3 天：加一条博物馆或迪士尼线
- 4 天：更适合做“经典 + 休闲”平衡

## 最佳旅游时间
- 春秋最舒适
- 夏季湿热但夜景和商圈体验依然强
- 冬季偏湿冷

## 核心景点与玩法
### 外滩 + 南京东路
- 适合第一次来上海
- 建议傍晚到夜间安排

### 陆家嘴
- 适合看天际线、城市地标和现代都市感
- 可与外滩形成一组经典对照

### 武康路 / 安福路 / 衡复风貌区
- 更适合 citywalk、咖啡馆和拍照
- 情侣和朋友出游很合适

### 上海博物馆 / 中华艺术宫 / 西岸
- 适合文化类和轻松慢游用户

### 上海迪士尼
- 适合亲子和乐园型游客
- 最好单独安排一整天

## 住宿区域建议
### 人民广场 / 南京西路
- 交通和综合便利性都很强

### 静安寺 / 常熟路
- 更适合想体验上海生活感和 citywalk 的人

### 陆家嘴
- 适合看夜景和商务型住宿
- 预算一般会更高

## 美食与觅食区域
- 本帮菜、小笼、生煎、葱油拌面都值得尝试
- 觅食区域：静安、黄河路、淮海中路、愚园路一带

## 交通建议
- 地铁非常强，优先级高
- 市区跨区通勤会消耗时间，建议按区域排
- 迪士尼行程单独规划

## 常见行程组合
### 3 天经典版
- Day 1：外滩 + 南京东路 + 陆家嘴夜景
- Day 2：武康路 / 安福路 citywalk
- Day 3：博物馆或迪士尼

## 避坑提醒
- 上海很大，不要低估通勤时间
- 只玩 2 到 3 天时，迪士尼和市区经典不建议都排太满
- 外滩更适合傍晚和夜里
