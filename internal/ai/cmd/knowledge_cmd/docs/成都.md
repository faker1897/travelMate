# 成都旅游攻略

## 城市定位
成都适合喜欢美食、慢生活、熊猫、川西中转和夜间休闲的人。
整体节奏偏松弛，很适合 2 到 4 天的城市度假型玩法。

## 适合人群
- 美食爱好者：火锅、串串、川菜、小吃密度高
- 情侣和朋友：宽窄巷子、玉林路、夜生活和周边短途都合适
- 亲子家庭：大熊猫基地有很强吸引力
- 想去川西的人：成都非常适合作为出发和休整城市

## 推荐游玩天数
- 2 天：市区经典打卡 + 美食
- 3 天：市区 + 熊猫基地
- 4 天：市区 + 都江堰 / 青城山

## 最佳旅游时间
- 春秋最舒适
- 夏季闷热但夜生活丰富
- 冬季相对阴冷，但吃喝体验依然在线

## 核心景点与玩法
### 成都大熊猫繁育研究基地
- 适合首次到成都和亲子游客
- 建议尽量早去，熊猫活动更活跃
- 热门时段人很多，要留足排队和步行时间

### 宽窄巷子
- 更适合游客第一次感受成都氛围
- 可以逛，但不一定要安排太久

### 人民公园 + 鹤鸣茶社
- 适合感受成都慢生活
- 更适合半天轻松行程

### 春熙路 / 太古里
- 适合逛街、吃饭、夜间活动
- 商圈成熟，第一次来成都住这里也方便

### 杜甫草堂 / 武侯祠 / 锦里
- 更偏历史人文线
- 锦里更游客向，适合顺路感受气氛

## 住宿区域建议
### 春熙路 / 太古里
- 吃饭逛街都方便
- 适合第一次来成都、重视便利性的人

### 宽窄巷子 / 人民公园附近
- 更适合偏 citywalk 和老城氛围的人

### 南门高新区
- 适合商务或对住宿条件要求更高的人

## 美食与觅食区域
- 必吃代表：火锅、串串、冒菜、甜水面、钟水饺、担担面
- 觅食片区：春熙路、建设路、玉林、奎星楼街
- 游客区更适合逛，认真吃可以多看本地口碑店

## 交通建议
- 地铁覆盖广，市区通勤便利
- 熊猫基地、都江堰等远一点的点位要单独安排时间
- 高峰期热门商圈打车会慢

## 常见行程组合
### 3 天经典版
- Day 1：人民公园 + 宽窄巷子 + 春熙路夜逛
- Day 2：熊猫基地 + 太古里
- Day 3：武侯祠 + 锦里 + 美食收尾

## 避坑提醒
- 宽窄巷子和锦里更适合看氛围，不一定适合做整天主行程
- 熊猫基地晚去体验会明显下降
- 如果只有 2 到 3 天，不建议同时塞都江堰和太多市区景点
