# 通用旅行规划指南

## 适合先确认的信息
- 目的地或想去的城市类型
- 出行时间
- 游玩天数
- 预算范围
- 同行人
- 偏好：风景、美食、历史、亲子、拍照、休闲、特种兵式打卡

## 行程规划基本原则
- 第一次去一个城市，优先安排经典片区，不要把行程排得过散
- 一天内尽量以 1 到 2 个片区为主，减少来回通勤
- 如果用户时间有限，优先保留“最有代表性的景点 + 最有体验感的夜间安排”
- 如果用户预算有限，优先住地铁站附近而不是最核心景区门口

## 住宿区域选择原则
- 第一次到访：优先住交通便利且靠近核心片区的区域
- 家庭亲子：优先住安静、出行简单、晚间餐饮方便的区域
- 情侣和朋友：可以优先住夜景、夜游或商圈附近
- 早班车/早班机：优先考虑与车站、机场通达效率

## 交通安排原则
- 市内旅游一般优先地铁和步行
- 节假日景区周边网约车容易堵，不要全程依赖打车
- 远郊景点要单独留足半天或一天，不建议和市中心高密度混排

## 输出旅游建议时的推荐结构
- 总体判断：这趟旅行更适合什么节奏和重点
- 推荐行程：分日或分片区写清楚
- 住宿建议：给出区域而不是只给酒店名
- 交通建议：大交通和市内交通都提一下
- 美食与体验：补充最值得安排的内容
- 避坑提醒：给真正有帮助的提示
