# 南京旅游攻略

## 城市定位
南京适合喜欢历史遗迹、博物馆、民国气质、城市夜景和本地小吃的人。
它的节奏比北京更松，但历史密度同样很高，适合 2 到 3 天深浅结合地玩。

## 适合人群
- 历史文化爱好者：中山陵、明孝陵、南京博物院含金量很高
- 情侣和朋友：秦淮河夜游、老门东夜逛体验很好
- 周末城市游用户：2 天即可玩出不错的完成度
- 第一次来华东历史城市的人：南京是很稳的选择

## 推荐游玩天数
- 2 天：适合经典打卡
- 3 天：适合经典景点 + 老城区慢逛
- 4 天：可加入牛首山、汤山或更细的博物馆线路

## 最佳旅游时间
- 3 到 5 月：春季舒适，适合步行
- 9 到 11 月：天气稳定，城市观感最好
- 盛夏：闷热明显，白天行程要注意体力分配

## 核心景点与玩法
### 中山陵
- 适合第一次来南京
- 免费但经常需要预约
- 台阶多，建议早去并穿舒适鞋

### 明孝陵
- 适合和中山陵放在同一片区
- 石象路很适合拍照
- 秋天气氛尤其好

### 南京博物院
- 中国顶级综合博物馆之一
- 展线丰富，认真看很耗时间
- 如果你对历史感兴趣，建议留至少半天

### 夫子庙 / 秦淮河 / 老门东
- 更偏夜游、散步和小吃体验
- 夫子庙游客更多，老门东更适合慢慢逛
- 晚上安排在这一片区会更有氛围

### 南京城墙
- 玄武湖段观景体验比较好
- 适合和鸡鸣寺、玄武湖搭配

## 住宿区域建议
### 新街口
- 优点：交通最方便，吃饭购物选择多
- 适合第一次来南京、想兼顾效率和生活便利的人

### 夫子庙 / 老门东附近
- 适合想把夜游体验放大的游客
- 晚上氛围好，但热门时段会更嘈杂

### 玄武湖 / 鼓楼附近
- 更适合偏安静、想兼顾景观和通勤的人

## 美食与觅食区域
- 必吃代表：盐水鸭、鸭血粉丝汤、牛肉锅贴、小笼包
- 小吃密集区域：夫子庙、老门东、新街口
- 南京适合边走边吃，但热门景区里也容易踩到普通游客店

## 交通建议
- 地铁足够覆盖主要旅游区
- 钟山风景区内步行量较大，要留体力
- 景点相对分散，建议按“钟山片区 / 老城片区 / 新街口片区”来排

## 常见行程组合
### 2 天经典版
- Day 1：中山陵 + 明孝陵 + 南京博物院
- Day 2：夫子庙 + 秦淮河 + 老门东 + 夜景

### 3 天舒适版
- Day 1：中山陵 + 明孝陵
- Day 2：南京博物院 + 新街口
- Day 3：南京城墙 + 鸡鸣寺 / 玄武湖 + 老门东夜逛

## 避坑提醒
- 钟山风景区景点多，不要一天内塞太满
- 夏天白天暴晒和闷热感明显，补水和休息节奏要跟上
- 夫子庙适合感受夜景，但正餐体验不一定是全城最优
- 如果只有 2 天，不建议安排太多跨城远距离点位
